One word for your Wi-Fi: **Ghosted**. Home Wi-Fi's most recognisable move is vanishing mid-sentence — right in the middle of a call, a match, a download — with no warning and no explanation. That is exactly what being ghosted is. One familiar word, borrowed from dating, pinned on a router: funny at once, true about how home Wi-Fi actually behaves, and not the word everyone reaches for. As a network name it works on its own — a neighbour scrolling the network list reads "Ghosted" and smiles, because theirs does it too.

## Run it

```sh
python3 main.py
```

Writes the word (7 characters, one word) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Pure Python standard library, no dependencies. The program enforces the competition gate itself — 1–20 characters, a single word, valid UTF-8, not blank, letters only, no whitespace — and verifies by reading the file back before exiting.
